Zoomies ink prototypes

Five ways to put text and drawing in one note. Each one shows the file it would save, live, on the right.

Is there a format for text with a drawing on top?

Yes, several. None is a single universal standard, but each prototype here saves to something that already exists, so the notes stay readable outside Zoomies.

What it would take in the Mac app

  • All five are buildable in AppKit. Text stays in NSTextView; ink is a transparent view on top that draws NSBezierPath strokes.
  • Pinning ink to words (1, 4) needs the text layout to report where a character sits. TextKit 2 gives that through NSTextLayoutManager. The ink view redraws whenever layout changes.
  • Pressure comes free with a tablet or Apple Pencil through Sidecar. On a trackpad, width is simulated from speed, as in these demos.
  • PencilKit exists on macOS only as drawing data, not as a canvas view, so a custom ink view is the realistic route.
  • Lowest risk: 2 and 3, because they only add images to the Markdown the editor already writes.
