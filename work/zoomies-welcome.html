Welcome to Zoomies

Hello! Please take 30 seconds to get set up and give Zoomies a proper chance. I recommend Cmd+Shift for Zoomies and Option+Shift for macOS screenshots. Change macOS shortcuts first: System Settings → Keyboard → Keyboard Shortcuts → Screenshots. Then change Zoomies shortcuts: menu-bar icon → Settings → Shortcuts. Default shortcuts (before swapping): • Option+Shift+4 → Area capture • Option+Shift+3 → Full-screen capture • Option+Shift+2 → Edit or rename an image selected in Finder • Option+Shift+1 → Create a scratchpad note Allow Screen Recording on your first capture, or enable it later in System Settings → Privacy & Security → Screen Recording.
