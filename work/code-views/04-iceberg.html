Evidence

Illustrated from the current code (working copy, 2026-09-12). File lengths from work/code-views/facts.json are size context only — not depth or quality.

  • Preferences keeper — Sources/SettingsStore.swift (127 lines). Public surface: load(), update, readable settings, didRepairInvalidSettingsOnLastLoad. Inside: Application Support path, legacy ~/.screenshot_app_settings.json migrate, JSON decode, normalize/repair, create parent folders, atomic write. Call sites include AppDelegate.swift (load ~21; repair notice ~101), SettingsWindowController.swift, and screens that read settingsStore.settings. Model: Sources/Settings.swift.
  • Secrets in a screenshot — Sources/PNGMetadata.swift (337 lines). Public: embed, extract, extractEditorState, isPNG, pixelDimensions. Inside: PNG chunk walk, uncompressed iTXt build/parse, strip prior Zoomies keywords, editor-state JSON encode/decode, safety size limits, CRC checksums. Call sites: WorkflowImagePersistenceLogic.swift, WorkflowReopenMetadataLogic.swift, ImageSafety.swift, EditorCanvasState.swift. Keyword string constants are public but unused outside this file.
  • After a screenshot — Sources/ScreenshotWorkflowController.swift (1038 lines). Public: start(), cancel(), panel/editor handlers, onFinish. cancel() closes rename/note/editor and clears pending editor state; it does not call backup restore. Restore runs on user close paths via restoreOriginalFromBackupIfAvailable() (e.g. closeWorkflowWithoutDeleting, editor closeOnly) when a backup exists. Inside otherwise: panel orchestration, wait for first capture file, rename, backup before overwrite, note burn-in, PNG metadata via helpers, clipboard, delete confirm. Created from ScreenshotService.swift (~167). Helpers: WorkflowImagePersistenceLogic.swift, WorkflowReopenMetadataLogic.swift, WorkflowNoteRenderer.swift, rename/note/editor controllers.

Third example is ScreenshotWorkflowController (not EditorCanvasView). EditorCanvasView is 1916 lines in facts.json if a wider above-water tip is needed later.
